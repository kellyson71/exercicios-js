# Atividade DOM JS

**Disciplina:** Desenvolvimento de Sistemas Web (DSW)  
**Professor:** Irlan Arley Targino Moreira  
**Aluno:** Kellyson Medeiros  

Conjunto de exercícios práticos demonstrando manipulação dinâmica da árvore DOM (*Document Object Model*) utilizando JavaScript puro (Vanilla JS), HTML5 e CSS.

## Exercícios Desenvolvidos
- `index.html`: Portal principal para navegação interativa entre todos os exercícios.
- `1-lista.html`: Adição e remoção dinâmica de elementos em lista não ordenada.
- `2-contador.html`: Contador interativo com botões de incremento, decremento e reset.
- `3-tarefas.html`: Lista de tarefas (To-Do List) com inclusão e marcação de concluído.
- `4-tema.html`: Alternador de tema claro/escuro (*Dark/Light Mode*) dinâmico.
- `5-cadastro.html`: Formulário de cadastro com validação de campos em tempo real.
- `9-imc.html`: Calculadora de Índice de Massa Corporal (IMC) com feedback visual.
- `10-estoque.html`: Gerenciador simples de estoque com cálculo de totais e alertas.

## Como Executar
Abra o arquivo `index.html` em qualquer navegador web moderno para navegar entre os exercícios.
